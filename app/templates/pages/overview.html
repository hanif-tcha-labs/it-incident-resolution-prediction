Business Problem & Prediction Moment

Framing the regression problem within IT service management operations

When an IT incident is opened, support teams need realistic expectations of resolution time to prioritize resources, prevent SLA breaches, and manage stakeholder expectations.

Target Definition:

resolution_hours = timestamp of last resolution minus opening timestamp (opened_at). The target is highly skewed (median: 16.1 h, mean: 167.3 h, maximum: 8,070 h). Administrative closure (closed_at) is deliberately not used because it reflects ticketing delays (~120 h later) rather than active resolution work.

Prediction Moment:

At ticket creation (first logged event). Only information known at opening enters the model. Counters that increase during resolution (reassignments, updates) or fields recorded upon closure are strictly quarantined to eliminate data leakage.

Model Workflow

Stage Input Operation Output / Output Volume
1. Raw Log incident_event_log.csv Audit formatting, parse explicit dates, standardize missing values (?) 141,712 events, 36 columns
2. Reconstruction Event rows grouped by number Extract first event attributes; compute resolution timestamp from last resolution 24,905 incidents with valid target
3. Feature Selection Candidate attributes Strict temporal boundary filter: retain 13 categorical features; exclude leakage fields 13 features + target
4. Temporal Split Incident table sorted by opened_at Chronological partitioning: 60% train, 20% validation, 20% test Train: 14,943 | Val: 4,981 | Test: 4,981
5. Model Pipeline Train + Validation data OneHotEncoder (min_freq=30) + HistGradientBoosting on log1p(hours) Final fitted pipeline (MAE 117.2 h)
6. Final Evaluation Held-out Test Set Evaluated once on test set with 1,000 bootstrap iterations and subgroup audits Fitted model artifact
Model Performance Summary: The pipeline yields an 11.5% MAE reduction over the running median baseline. Fast-track tickets (<1 h) are resolved with high precision (MAE 8.2 h vs 20.4 h baseline), whereas complex cases exceeding 24 h represent 91% of cumulative forecast variance.
